# Machines have lucid dreams

![mhld_wind](https://github.com/user-attachments/assets/220fab3a-b698-48cf-9bc9-1e80a94afea8)

A full-length (2 hours) point-and-click adventure game made in Adventure Game Studio over 2 years.

## Key features
- Open world
- Multiple characters with heavily scripted dialogues
- Unique object combination mechanic
- Alternate endings
- Completed commercial-length project

## Play the game
Available to download and play for free on itch.io [kashngerm.itch.io/squirrel](https://kashngerm.itch.io/squirrel/)
