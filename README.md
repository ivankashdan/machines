# Machines have lucid dreams

![mhld_wind](https://github.com/user-attachments/assets/220fab3a-b698-48cf-9bc9-1e80a94afea8)

A full-length (2 hours) point-and-click adventure game made in Adventure Game Studio.



## Key features
- Open world
- Multiple characters with heavily scripted dialogues
- Unique object combination mechanic
- Branching paths and alternate endings
- Complete commercial-length project
- Save system
- Objectives
- Inventory
- SFX and music

## Play the game
Available to download and play for free on itch.io [kashngerm.itch.io/mhld](https://kashngerm.itch.io/mhld/)

## Explore the code database
This repo contains only the scripts for MHLD
- Thousands of lines of C++ conditional logic
- Consistent standards across in-game rooms
- A reliable, stable build of high complexity
